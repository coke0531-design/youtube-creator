## 3. 실사 소스 규칙(정본 문구, G r2 확정)

1. 실사는 항상 **카드 안 세상**: 카드 안(P2 cardFull) 고정 창 `WIN {x:1040, y:510, w:1316, h:740, r:32}`(카드 로컬 y 140~880, HUD 칩 아래 여백 ≥ 50px) 또는 무대 위 흰 카드 창(`inCard`, r 32). 둥근 모서리 + 잉크 테두리 4px. 각진 사각 금지.
2. 카메라 줌·팬은 **창을 움직이지 않고 창 안의 그림에만** 적용(창 클립). 카메라 규칙 4조 그대로.
3. 대사 구간 = 실사가 보이는 구간. 클립 길이는 **재생 속도**로 맞춘다(rate = 클립/대사, 0.6~1.5 허용, 보간 금지, 범위 밖이면 한계 속도 + 남는 시간 마지막 프레임 유지). 프레임 번호 = `floor((t - t0) * 30 * rate)`.
4. 결정론: `<video>` 금지, JPEG 시퀀스 + `live.js`(Image LRU 60, async seek, FILM_READY 전 첫 프레임 선로드). `capture.py --verify-seek` 필수.
5. 실사 위에 가짜 UI 덧그리기·앱 모양 흉내 요소 금지. 녹화는 확대·흐림 전환 없이 받는 것을 권장(필름 줌과 겹침).
6. DIRECTION `<입력>` 실물 소스 표: 파일 · 규격 · 내용 · 대사 구간(비트 #) · 카드 안/창 · rate.

### 6-3. 지시와 다르게 한 것

- 스모크 음성·SRT는 G 원본(386.9초)을 그대로 쓰면 mux가 마지막 프레임을 376초 늘린 386.9초 파일을 만든다(1회 실측). 10초 완성본이 목적이라 정본 `segment.py`로 G 앞 10초를 잘라 썼다(무음 aac·더미 srt 대신 실제 음성, segment.py까지 정본 경로로 검증).
- 스모크는 킷 담당 템플릿이 이미 있어 그것을 썼다(실험판 G1_live 대신). `--end 10`이라 템플릿의 실사 창 구간(13~22초)은 캡처 범위 밖이다 — 실사 결정론은 이번 스모크로 검증되지 않았다.
- SKILL.md 콜라주·HF·화이트보드 상세 절차는 한 문단으로 접으면서 본문을 지웠다(git 이력의 2026-09-14판에 남음). CapCut 조립 Step 8·8.5, 편집지시서/타임라인.json Step 6, 게이트 6.9~7.5도 같은 문단으로 옮겼다.

### 6-4. 확인이 필요한 것

- **CapCut 드래프트(요청 시) 경로가 필름 산출물에 바로 안 맞는다.** `assemble_capcut.py`는 시작 시 `validate_pipeline.py`(SLIDE_TIMELINE·콜라주 오프닝 검사 F)를 돌려 필름 경로에서는 중단된다. 지금은 "capture.mp4·narration·full.srt를 t=0에 수동 배치"로 적었다. 필름용 최소 타임라인 모드를 만들지는 오너 결정.
- 스모크 템플릿 6초 프레임에서 카메라 줌 뒤 땅선이 y ≈ 896(하단 200px 안, 자막 줄 바로 위)에 걸린다 — 킷 담당 템플릿 확인 필요.
- 캡처 속도가 워커당 0.7fps였다(같은 시각 킷 담당 캡처와 겹쳤을 가능성). 본편 전체 캡처 시간 예측은 단독 실행 기준으로 다시 잴 것.
