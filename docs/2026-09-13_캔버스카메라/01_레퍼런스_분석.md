## 2. 연출 문법 (실측으로 확인한 것)

### 2-1. 캔버스와 카메라
- 화면보다 큰 **캔버스** 위에 요소를 배치하고, **카메라**(전체 그룹의 이동+확대)가 그때그때 보여줄 곳을 잡는다.
- 카메라 이동의 이유는 세 가지다. ① 새 요소가 지금 화면 밖(또는 가장자리)에 생김(C·G·H) ② 이미 보이는 대상의 상태 변화 강조(B의 봇 전환 때 살짝 줌인) ③ 관계 재정리(마지막 넓은 샷). 이유 없이 움직이지 않는다.
- 이동 시간 약 0.8~1.2초, 양끝이 부드러운 이징(ease-in-out). 튐 없음.
- 확대 배율: 요소 하나를 잡을 때 약 1.4~1.6배(H, G). 표를 볼 때 약 1.2배(C).
- **요소가 누적되는 장면(C·G·H·F)은 넓은 관계 샷으로 마무리**한다. 부분을 하나씩 보여준 뒤 전체를 한 번에 보여주는 것이 "결론" 박자다. 줌아웃 뒤 3~5초 정지. 고정 카메라 장면(D·D2·E)에는 없다. H의 마지막 샷은 카드 가장자리가 일부 잘린 채라 "모두 완전히 들어오는 fit"과는 구분한다.
- 카메라가 움직일 때 앞 요소들은 화면 가장자리에 **일부 잘린 채 남는다**(C, H). 완전히 사라지지 않아 이어짐이 느껴진다.
- 팬과 줌은 자주 **동시에** 일어난다(G의 Anti 카드: 아래로 팬하면서 줌아웃).

### 2-2. 등장 방식 "유령 → 실체"
- 새 요소는 **옅은 상태로 먼저 자리를 잡고** 잠시 뒤 선명해진다(밀집 시트 기준 불투명도 약 0.25~0.4, 0.3~0.5초. 이 수치는 5fps 시트에서 읽은 값이라 참고값이다). 튀어오르거나 미끄러져 들어오지 않는다. 흐림(blur)이 실제로 있는지는 JPEG 압축과 구분되지 않아 미확인.
- 카드는 **틀 → 헤더(제목·배지) → 내용(아이콘 → 화살표 → 칩)** 순서로 채워진다. 각 조각이 나레이션 어절 하나씩에 붙는다.
- 아이콘은 제자리에서 옅게 나타나며 약간 커진다(0.95→1). 화살표·점선·구름 외곽선·시계 호는 **선이 그어진다(draw-on)**.
- 칩(알약)은 **왼쪽에서 오른쪽으로 하나씩** 0.15~0.2초 간격. 미니 흐름("설치 → 서버 → 모델 → …")도 마디 하나씩.
- 같은 자리 **바꿔치기(제자리 상태 교체)**: B에서 사람 아이콘이 봇 얼굴로, "profile" 칩이 "bot" 칩으로, 캡션 문장이 다른 문장으로 바뀐다. 이동 없이 제자리 교차. 형태가 이어지는 morph는 아니고, 정체성이 유지되는 대상의 상태 교체다.
- 장면 안 소장면 전환(D→D2→E)은 **전체 흐림 교차**(앞 장면이 옅어지며 뒤 장면이 옅게 올라옴, 약 0.5초).

### 2-3. 큐와 정지
- 등장은 **나레이션 어절에 붙는다**(5fps 시트와 자막 대조 기준. 발화 시작과 첫 가시 프레임의 오차는 프레임 단위로 재지 않았다). 예: "그록봇은 애플이고" → Apple 로고, "리눅스다" → Linux 펭귄, "다만 비용이" → 단점 카드, "반면 헤르메스" → Hermes 카드.
- 큐 사이는 **정지 화면이 길다**. 5~8초 정지가 흔하다(H의 각 카드 뒤, A의 목차 완성 뒤 7초). 카메라나 요소가 "숨쉬기"로 흔들리지 않는다. 우리 교리 3법칙("나쁜 모션보다 정지")과 같은 태도다.
- 큐 하나에 요소 하나. 한 번에 여러 개를 쏟지 않는다.

### 2-4. 진행형 표(C)
- 헤더 행(비유·대상) 1행 + 본문 4행. 첫 행(헤더)만 놓고, 나레이션이 다음 축("가격·세팅", "모델", "기능", "사용성")을 말할 때 **행이 아래에 하나 붙고 표 전체가 위로 밀린다**(넛지). 가운데 세로에 축 이름 검은 알약.
- 밀릴 때 위 행은 화면 위로 일부 잘려 나간다. 마지막에 줌아웃하면 5행 전체가 보인다.

### 2-5. 시각 어휘
- 배경 2종: **모눈 흰 배경**(개념·구조 설명) / **흐린 유화 이미지**(비교·총평, 채도 낮게, 카드가 떠 보이게).
- 카드: 흰색, 1px 옅은 테두리, 둥근 모서리 14~18px, 옅은 그림자. 카드 위에 아주 작은 회색 라벨("Grok Bot", "Hermes")이 따로 떠 있다.
- 칩 3종: 테두리만(중립) / 검정 채움(강조·축 이름) / 고정폭 글꼴("profile", "only", "bot").
- 부정은 "✕" 칩 또는 점선 구름에 ✕.
- 아이콘은 단색 선화(1.5~2px). 색은 제품 아이콘(봇 얼굴 색)에만.
- 글씨: 굵은 산세리프 한글(Pretendard 계열), 숫자 번호 "01 02 03"은 세리프.

### 2-6. 들어가고 나가는 전환
- 화면 녹화 → 모션 그래픽: **줌스루**(앞 화면이 커지며 흰빛+흐림, 0.4초) 뒤 모션 그래픽이 나타남. 우리 벡터 예약표의 "Z 후퇴"와 같은 계열.
- 모션 그래픽 → 화면 녹화: 대부분 **바로 컷** 또는 흰 섬광 컷.
- 챕터 제목("3. Grok bot vs Hermes bot")은 화면 녹화 위에 노란 손글씨 타이핑으로 얹힘(모션 그래픽 아님, 제외).
