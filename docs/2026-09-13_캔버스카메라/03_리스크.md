# 리스크 점검: 접목했을 때 기존 시스템이 깨지거나 수준이 떨어질 가능성

판정 기준 = 실험 결과(`결과물/2026-09-13_캔버스카메라-AB실험/검증/`)와 코드 조사. "미확인"은 아직 재지 않은 것.

## 1. 기존 시스템이 깨질 위험 (기술)

| 항목 | 위험 | 실측·근거 | 판정 |
|---|---|---|---|
| 캡처 결정론 | 카메라 트윈이 프레임마다 다른 값을 내면 청크 경계에서 튐 | 흐름 1구간 2회 캡처 560프레임 픽셀 차이 0(`B_recapture_diff.txt`). 새 페이지 직행 seek와 순방향 seek 표본 지점 픽셀 차이 0(`B_seek_determinism.txt`, 열 이름·조건 명시본). 범위 = 캡처 경로(새 페이지+순방향)만 | 캡처 경로에서 안전. 역방향·임의 순서·청크 경계는 미확인 |

## 2. 수준이 떨어질 위험 (연출·품질)

| 항목 | 위험 | 실험에서 본 것 | 대응 |
|---|---|---|---|
| 게이트 통과 착시 | 카메라가 움직이면 check_motion 점수가 좋아져 품질 증거로 오해 | 위험은 실재한다. 카메라 3장면 모두 B 점수가 A보다 낮아졌다(흐름 B는 WARN). 동시에 이 게이트는 흰 배경 작은 요소 등장을 정지로 읽는다(A 4장면 96~100%). 어느 만큼이 검출 누락이고 어느 만큼이 실제 홀드인지는 미분리 | 임계 완화 금지. 계획된 트윈 목록이 아니라 의미별 가시성 감사표(큐·화면 안 도착·읽을 크기·홀드)를 병기 |
| 미니멀 무드 훼손 | 모눈·회화 배경·그림자 과다 | 실험은 흰 배경·옅은 테두리·옅은 그림자만. 모눈은 뺐다 | 배경 무늬는 채택 안 함 |
| 읽기 크기 | 전체 보기에서 글자가 작아짐 | 1차 fit 배율: 흐름 0.81 · 목록 0.66 · 비교 0.63(칩 26px → 16~21px). 1차에는 목록·비교의 전체 보기 뒤에 결론 칩이 처음 나왔다(규칙 위반, astra 2라운드) → 2차: 비교 fit 생략, 목록은 3행+결론 샷(배율 약 0.9), 흐름 fit만 유지(요약 칩은 이미 말한 세 갈래의 요약) | 규칙: 전체 보기 뒤 새 결론 금지, 본문 최소 18px, 중요 선 3px 이상 |
| 비교 기능 상실 | 한 카드만 크게 잡으면 상대가 안 보임 | 1차(`.k→.L→.R` 카드별 팬)는 astra 2라운드가 "비교가 아니라 차례 소개"로 판정 → 2차: 기준 카드 → 양쪽 조건 행(배율 0.95) → 홀드. 기준 카드 아랫단이 화면에 남고 보조 라벨(책임 있음/없음)을 칩으로 바꿔 대비를 올렸다 | 오너 판정 항목 |
| 화면 밀도 | 카드가 화면에 비해 작게 보일 수 있음 | 첫 샷의 카드 1장이 화면 폭의 28%였다. 배율 상한이 1이라 pad 축소로는 안 커진다 → 2차: 흐름 카드를 폭 620~660으로 키우고 분기 열 간격을 줄여 세 분기가 한 샷에 들어오게 | 채택 시 카드·타이포 기본 크기를 캔버스 규격으로 다시 정함 |
| 예측 가능한 반복 | 모든 카드가 틀→헤더→내용으로 같은 박자 | 첫 카드만 틀 예고, 이후 카드는 의미 단위로 바로(목록 장면 행 1·3은 통째 등장) | 규칙으로 명시 |
| 워커 자유도 | 프레임마다 다른 배율·이징 | 배율은 헬퍼가 계산(zoom 상한 1), 이징 기본값 고정 | 감독이 레이아웃·카메라 계획 지급 |
| 대본 밖 결론 | fit을 위해 홀드를 늘림 | 오디오·큐 불변. 1차에서 목록·비교는 전체 축소 뒤에 결론 칩이 처음 나와 읽을 시간이 0.2~0.75초뿐이었다(astra 2라운드) → 2차: 비교는 마지막 fit 생략(행 단위 샷에서 결론을 읽음), 목록은 전체 축소 대신 3행+결론 샷. 흐름의 fit 뒤 요약 칩은 이미 말한 세 갈래의 요약이라 유지 | 규칙: 전체 보기 뒤 새 결론 금지. fit 큐가 없으면 fit 생략 |

## 4. astra 2라운드가 잡은 것 (2026-09-13, `_advice/astra_r2.md`)

- 실험 설계: A(카메라 고정)는 "같은 큰 캔버스를 축소한 것"이라 "현행 방식으로 잘 그린 고정 화면"을 대표하지 못한다. 현재 실험은 "같은 캔버스에서 고정 vs 이동"에만 답한다. 필요하면 A1(현행 방식 최적 고정 구현)을 별도 추가.
- 1차 B 결함 3건(비교 카드별 팬으로 기준·상대 손실 / 목록·비교의 전체 축소 뒤 결론 등장 / 흐름 첫 카드 작음·분기 잘림) → 2차 반영.
- 검증 표기: "전 프레임"이 10fps 표본이었음 → 30fps 전 프레임로 재검사. seek 로그에 무관한 역방향 결과가 섞여 있었음 → 열 이름·조건을 명시한 로그로 교체.
- 헬퍼: `seek 왕복 안전` 주석 삭제, fit `targets` 필수, 입력 검증, 요소별 immediateRender.
- 판정 페이지: 제목·질문에 정답과 가설이 새고 있었음 → 중립 장면 번호, 클립별 자유 회상, 정답·게이트·출고본은 답 8개 뒤에만 공개, 동시 재생 차단, 답변 파일 저장.
- 게이트: FAIL을 "센서 둔감"으로 지우지 말 것. 출고 정책이 FAIL 금지면 지금 상태로 출고 불가. 예외 절차 없이 투입 금지.
