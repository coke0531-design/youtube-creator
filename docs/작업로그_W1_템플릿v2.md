## 2. 템플릿 v2 개정 내역

**(a) 슬라이드 로컬 GSAP 타임라인 계약**
- `<head>`에 `<script src="gsap.min.js">`(상대경로) + `window.__slideTimelines = {}` 초기화. **콘텐츠/타임라인 정의 스크립트보다 앞**.
- 슬라이드 마크업 뒤 · 내비게이션 스크립트 앞에 타임라인 등록 전용 `<script>` 슬롯 신설(예시 주석 포함).
- 표시: `<section class="slide" data-tl="s07">` → `__slideTimelines["s07"] = gsap.timeline({paused:true}).fromTo(...)`.
- 구동: `driveTimeline(slide, local)` — `local = t − entryTime`,
  `tl.totalTime(min(local,dur)+0.001, true); tl.totalTime(min(local,dur), false)`. **`tl.seek()` 미사용**(파일 내 `tl.seek` 호출 0건, 금지 주석만 존재).
  · `__capture.seek(t)`에서 매 프레임 호출 · `startAutoplay`의 rAF tick에서도 동일 구동(타임라인이 아직 진행 중이면 tick을 계속 요청하도록 종료 조건 확장)
  · `applyEntry`가 슬라이드 전환 시 `entryTime = e.t`로 로컬 원점을 잡는다
  · 수동 넘김(방향키·캡처 아님)은 `tl.play(0)`, 캡처/오토플레이는 `tl.pause(0)` 후 seek 구동. 다른 슬라이드 타임라인은 0으로 되감음
- 파일 상단 주석에 v2 계약 요약 + 배포 규약(`벤더/gsap.min.js` → `04_영상소스/gsap.min.js` 동봉) + 금지 목록(seek()/progress()·무한 repeat·Date.now·Math.random·CSS transition과 GSAP 이중 구동·스크립트 순서).

**(b) weighted stagger preset**
- `.el--w-anchor`(6.5vh ≈ 70px @1080, 0.18s) / `.el--w-norm`(4.2vh ≈ 45px, 0.145s) / `.el--w-light`(3.3vh ≈ 36px, 0.115s), 이징 `cubic-bezier(0.16,1,0.3,1)`(power3.out).
- 캐스케이드 후반 간격 감소: `transition-delay: max(0ms, calc(var(--i)*80ms − var(--i)*var(--i)*4ms))` → 0/76/144/204/256/300/336/364/384ms. `--i`는 0~8 범위(주석 명시).
- 기존 `.el` 기본 스태거는 **그대로 유지**(하위 호환).

**(c) 넛지 커브 preset**
- `.nudge` + `@keyframes nudgeX`: 거리 10/65/25%, 시간 20/18/62%, 램프인 `cubic-bezier(0.55,0,1,0.45)` → 선형 버스트 → `cubic-bezier(0.22,1,0.36,1)` 꼬리.
- 변수: `--nx`(이동 거리) / `--nd`(시간) / `--ndelay`. 주석에 "새 콘텐츠는 버스트 구간(20~38%)에 드러낸다" 명시 + `.el` 계열과 같은 요소에 겹쳐 쓰지 말 것(transform 이중 구동).
- CSS keyframes는 캡처 가상시간을 그대로 따라 결정론이므로 허용(주석에 근거 기입).

**(d) 컷 더 커브 슬라이드 전환(옵트인 `.slide--cut`)**
- 들어오는 쪽: `cutIn` 0.36s `cubic-bezier(0.25,1,0.5,1)`, `translateX(12vw)→0`, opacity 0.35→1.
- 나가는 쪽: `#slide-container:has(> .slide--cut.active) > .slide.prev`에 `cutOut` 0.3s `cubic-bezier(0.5,0,0.75,0)`, `0→−12vw`, opacity 0을 **72% 키프레임**에 배치(power4.in에서 이동 거리 27% 지점 = 시간 72%).
- 기본 크로스 디졸브는 손대지 않음(옵트인하지 않으면 현행 그대로).

**(e) 수정 2건**
- `.pulse`: `infinite` → `3`회(약 6초) + 청크 경계 위상 튐 방지 주석.
- 캡처 preroll: `?capture=1`이면 `body.preroll` 부착 → `body.preroll #slide-container *`에 `transition/animation: none !important`. 첫 `__capture.seek()`에서 해제 후 슬라이드 0 재활성화.
  **🔑 순서가 계약(1차 캡처 실패로 실측 확정)**: ① preroll 상태에서 `active/prev` 제거 → ② 리플로우 → ③ `preroll` 제거 → ④ 리플로우 → ⑤ `go(0)`.
  ①②를 건너뛰고 preroll 해제와 active 제거를 같은 재계산에 넣으면 트랜지션이 켜지는 순간 opacity 1→0 트랜지션이 시작되고, 곧바로 active를 다시 붙이며 되돌아가 **프레임 0에 이미 완성 화면**이 된다.

**(f)** 파일 상단 v2 계약 요약 주석 — (a)에 포함.

## 4. 남은 문제 · 후속

1. **9:16 템플릿 미반영** — `템플릿/presentation-9x16.html`에는 v2가 들어가지 않았다(범위 밖). 쇼츠에 같은 계약이 필요하면 별도 작업.
2. **design.md §4 렉시콘 등재 미완** — `스태거--무게` / `넛지 커브` / `컷 더 커브` 3종은 구현만 됐고 SSOT 표 등재는 다른 워커 담당(지시상 수정 금지). 등재 전까지 "용어 따로 구현 따로" 상태.
3. **`cutOut` 불투명도 근사** — 설계의 "이동 25~30% 지점에서 0"을 따라 72% 키프레임을 썼다. 지시문에 병기됐던 "opacity 지속 ≈ 0.09s"(선형 가정 환산)와는 수치가 다르다. 오너/감독 확인 항목.
4. **`:has()` 의존** — 컷 전환의 나가는 쪽 규칙은 `:has()`를 쓴다. 캡처는 Chromium 고정이라 안전하지만, 다른 브라우저에서 열면 나가는 슬라이드만 기본 크로스페이드로 폴백된다.
5. **weighted stagger `--i` 상한 8** — 간격 감소 수식이 i=10에서 정점을 찍고 역전된다. 요소가 9개 이상이면 그룹을 나눠야 한다(주석에만 기록, 기계 검사 없음).
6. **모션 게이트 미연동** — `check_motion.py`(정지 화면 회귀 검출)는 이번 범위 밖. 스모크의 S01·S03은 루트가 없어 정지 구간이 길다.
7. **ATTRIBUTIONS 등재** — GSAP 벤더 반영 건은 `~/my-claude-config/attributions/ATTRIBUTIONS.md`에 1항목 추가 필요(이 워커 범위 밖이면 감독이 처리).
