## P1+P2 혼합 규칙 (v3.2, 기본)

- **세계가 둘이다.** P1 종이 무대 = 카드 밖 세상(캐릭터가 겪고, 비교하고, 결론 내는 곳). P2 스튜디오 = 카드 안 세상(화면 속 일: 조작·파일·구조·명령·UI 비교). 영상은 P1에서 시작해 P1에서 끝난다.
- **P2로 들어가는 길은 하나, 카드 줌.** 캐릭터 앞(또는 옆)에 흰 카드가 있고, 화면 속 일을 설명할 때 카메라가 0.5초 동안 그 카드로 들어가 카드가 화면을 채운다(`KIT.enterCard(p)`). 안에서는 P2 규칙(컷 없음·모프·120BPM·커서·입력창·토큰). 끝나면 0.5초 줌 아웃(`KIT.leaveCard(p)`)으로 캐릭터가 그 카드를 들고 있거나 옆에 선 무대로 돌아온다. 컷으로 팩을 바꾸지 않는다.
- **팔레트·글꼴은 P1 하나.** P2 회백 캔버스 대신 미색 종이 위 흰 카드. 잉크·앰버·그린 4색, Pretendard. 종이 그레인은 카드 밖에만.
- **비트 성격으로 팩을 정한다(비트 표 팩 열에 P1/P2).** P1 = 주장·실패담·사람/시간/돈 비교·결론·정리·CTA·감정. P2 = 조작(메뉴·명령·타이핑)·파일·조직도·설정 도식·UI 안 결과물 비교. 한 P2 구간은 10~60초(조작 하나면 7초도 됨), 영상당 2~6회. **카드 안에는 토큰(나)이 상주**해 캐릭터와 이어진다(G·H 실측: 43·48·24초 P2 구간도 토큰 상주로 충분).
- **빈 카드 금지(G·H 실측).** 줌 인 전 무대의 흰 카드 안에 이미 내용이 작게 보이고, 줌 아웃 뒤에도 내용이 남는다. 카드 안 내용이 줌 중에야 나타나지 않는다(장치 21 뼈대 선행의 카드판).
- **주인공 연결.** P1 캐릭터(별표 8비트, ≥270px) ↔ P2 토큰(원형 아바타 ≥200px)은 같은 별표 마크를 쓴다. 카드 안에서 "나/AI"가 필요하면 토큰, 카드 밖이면 캐릭터. 군단은 캐릭터 복제(P1) 또는 토큰 복제(P2).
- **HUD 칩·챕터 칩은 팩 밖 요소**(줌에 따라 움직이지 않는다).
- **선은 곧게, 끝만 둥글게**(손그림 흔들림 금지, 두 팩 공통).

> "분야 하나 + 스타일 하나"가 레퍼런스 10편의 첫째 공통점이다. 팩은 팔레트·글꼴·질감·주인공·모션 성격을 한 묶음으로 정한다.
> 브랜드 규칙과의 관계: 4색(잉크·앰버·앰버 텍스트·그린)은 그대로, 배경만 종이 미색 `#F7F3EA`(design.md §4-A).

## P1. 종이 무대 (브랜드 4색 판) — **기본, 카드 밖 세상**

- 팔레트: 종이 `#F7F3EA`(흰 대신 미색), 잉크 `#141413`, 강조 앰버 `#F59E0B`(작은 글자 `#D97706`), 보조 그린 `#16a34a`. **전면 색 패널 허용**: 챕터 카드·결론 비트에 잉크 배경 또는 앰버 배경 전면 사용(**러닝타임 10% 이하**, 오너 결정 9/29).
- 글꼴: 제목 Pretendard ExtraBold, 본문·숫자 Pretendard(숫자 tabular). 픽셀 폰트는 하이스코어 보드 장치에만 예외.
- 질감: 옅은 종이 그레인(불투명도 6~8%). **선은 곧게, 끝만 둥글게.** 손그림 흔들림(획 떨림)은 쓰지 않는다 — 오너 판정(9/29 C세트): 삐뚤빼뚤한 검은 선이 지저분해 보인다. "그려지는 과정"(draw-on)은 곧은 선으로도 그대로 한다.
- 주인공: 클로드 별표 로고를 몸으로 쓰는 8비트 캐릭터 1명(눈·자세 3종) + 땅선 무대. 좌상단 스테이지 HUD.
- 모션: 하드컷 중심, 비트 경계마다 변화, 스케일 인 도장, 카운트, 막대 성장. 카메라는 고정이 기본.
- **크기(v3.1)**: 캐릭터 높이 ≥ 270px(화면 25%), 핵심 숫자 ≥ 130px, 카드·시계·게이지 같은 장치 본체 ≥ 화면 폭 30%. 작은 소품은 큰 요소 옆에서만.
- **구도(v3.1)**: 무대 장면은 3초마다 컷·큰 이동·새 요소 입장·줌 중 하나. 하드컷 첫 프레임에 뼈대(땅선·HUD·도식 윤곽)가 이미 있다.
- 출처: nahiddotai ⑨ 구조에 브랜드 색을 입혔다.

## P2. 스튜디오 모노 — **카드 안 세상**(v3.2에서는 P1 카드 안에서만 쓴다. 회백 캔버스는 쓰지 않고 흰 카드가 캔버스다)

- 팔레트: 따뜻한 회백 `#EDEBE6` 캔버스, 검정 `#111`, 흰 `#FFF`, 강조 1색(앰버 `#F59E0B`).
- 글꼴: Pretendard 1종(굵기만 3단).
- 질감: 없음(평면 + 부드러운 그림자 1단).
- 주인공: 흰 둥근 카드 하나가 상태에 따라 변신(조직도 판·입력창·문서·비교 판·원칙 카드…). 커서가 실제로 누른다. 사람·모델·도구는 **원형 아바타 토큰**(지름 ≥ 200px, 이름은 대본에 있는 것만)으로 그린다 — P1의 캐릭터를 대신한다.
- 모션: 컷 없음. 스프링(닫힌 식) 모프, 카메라 줌으로 각 상태를 꽉 채움. 120BPM 그리드. 모프 시작 프레임에 목표 형태의 점선 윤곽(장치 21). **카메라는 상태가 바뀔 때 한 번 움직이고 3초 이상 머문다**(SKILL.md §4-3 카메라 규칙: 줌 ≥0.15·팬 ≥15%, 6초 안 왕복 금지, 이동당 ≥4초). 줌인·줌아웃을 박자처럼 반복하지 않는다(G4 실측: 1.5초마다 1.0↔1.1 왕복 = 오너 "과하다").
- 크기·구도(v3.1): 카드 폭 ≥ 1150px, 아바타 ≥ 200px, 명령 글자 ≥ 44px, 문서 안 글자 ≥ 40px(D세트 약점: 34px는 휴대폰에서 작음). 3초마다 모프·줌·입장 중 하나.
- 영역별 쓰는 법(기본 팩이 되면서 확장): 조작 = 입력창·타이핑·커서 / 개념 = 조직도·토큰 연결 / 비교 = 두 줄 비교 판 + 스위치 / 효과 = 게이지(수치 없음) / 실패담·경고 = 토큰이 회색으로 꺼지거나 빈 홈(▲ 조각으로 메움) / 결론 = 첫 도식이 작게 돌아옴(수미상관).
- 언제(v3.2): 조작·파일·구조·명령·UI 안 비교 비트. 카드 줌으로 들어가고 나온다.
- 출처: twoclipping ③.

### P2 안의 실사 창 (v3.2 r2, 2026-09-30 오너 확정 — 규칙 원문 = SKILL.md §4-4)

- 실사(화면 녹화·실물 영상)는 **항상 카드 안 세상**이다. 두 자리만 쓴다.
  - 카드 안(P2 cardFull) 고정 창: `WIN {x:1040, y:510, w:1316, h:740, r:32}`(카드 로컬 y 140~880, HUD 칩 아래 여백 ≥ 50px, 왼쪽 끝이 토큰보다 오른쪽).
  - 무대 위 흰 카드 창(`inCard`): P1 무대에서 실사를 잠깐 보일 때. 역시 r 32.
- 둥근 모서리 + 잉크 테두리 4px. 각진 사각 창·화면 전체 덮기 금지. 창이 작아지는 장면(축소·카드로 넘어감)에서도 모서리·테두리는 크기에 비례한다.
- 카메라 줌·팬은 **창을 움직이지 않고 창 안의 그림에만** 건다(창으로 자른 뒤 확대). 카메라 규칙 4조 그대로.
- 실사 위에 가짜 UI·앱 모양 흉내 요소를 덧그리지 않는다. 설명 칩·괄호는 창 **밖**에.
- 실사가 어두운 테마면 대비가 크다. 창 테두리와 카드 여백으로 "화면 속"임을 분명히 한다.

## 팩 공통 규칙

- 한 편 안에서 쓰는 팩은 P1과 P2 둘뿐이고, 둘 사이는 카드 줌(enterCard/leaveCard)으로만 오간다. 컷으로 팩을 바꾸지 않는다.
- 팔레트 색 수는 4~5, 강조색 1개. 팔레트 밖 색은 로고·실제 UI 캡처에만.
- 글꼴 2종 이하. 한글 우선, 고유명사만 영어.
