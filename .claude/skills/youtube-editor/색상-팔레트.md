# 색상 팔레트 가이드 — 4색 원칙

**흰 배경 + 잉크 + 앰버(주 강조) + 그린(보조 강조). 이 구조만 사용한다.**

> 단일 출처: 프로젝트 루트 [design.md](../../../design.md) §2-3 영상 소스 모드.
> 구 팔레트(검정 배경 + 네온그린 `#00FF88` / 골드 `#FFD700` / 다크 앰버 `#FBBF24`)는 전부 폐기됐다.

## 팔레트

```
┌─────────────────────────────────────────────────────────┐
│  ⚪ #ffffff — 배경 (흰색 고정)                            │
│     표면/카드: #f7f6f4 · 빈 트랙: #efeeea                │
│                                                         │
│  ⚫ #141413 — 잉크 (텍스트·선·기본 도형)                  │
│     보조 텍스트: #5e5d59 · 메타 한정: #a39e98            │
│                                                         │
│  🟡 #F59E0B — 주 강조 (앰버)                             │
│     핵심·데이터·현재·CTA. 작은 텍스트는 #D97706          │
│                                                         │
│  🟢 #16a34a — 보조 강조 (그린)                           │
│     성공·체크·After·2번째 데이터 시리즈                  │
└─────────────────────────────────────────────────────────┘
```

## 색 역할 분담

| 상황 | 색 |
|------|------|
| 핵심 키워드/데이터/현재 단계/CTA | 앰버 (`#F59E0B`, 작은 텍스트 `#D97706`) |
| 성공/완료/체크(✓)/Before-After의 After | 그린 (`#16a34a`) |
| A vs B 비교 (둘 다 유효한 데이터) | A = 앰버, B = 그린 |
| 좋음 vs 나쁨 비교 | 좋음 = 앰버(또는 그린), 나쁨 = **뉴트럴** (`rgba(20,20,19,0.14)` 바 + 잉크 텍스트) |
| 부정/실패/× 마커 | **잉크** (`#141413`) — 색이 아닌 마커·맥락으로 부정 전달 |

## CSS 상수

```js
const COLORS = {
  bg: '#ffffff', surface: '#f7f6f4', track: '#efeeea',
  ink: '#141413', inkSub: '#5e5d59', meta: '#a39e98',
  accent: '#F59E0B',      // 주 강조 (그래픽·큰 숫자)
  accentText: '#D97706',  // 주 강조 (작은 텍스트)
  green: '#16a34a',       // 보조 강조
  border: 'rgba(20,20,19,0.08)', borderStrong: 'rgba(20,20,19,0.14)',
};
```

## 사용 패턴

```html
<!-- 섹션 라벨: 앰버 텍스트(#D97706) + 옅은 앰버 배경 칩 -->
<span class="section-label">비용 비교</span>

<!-- 강조 키워드: strong = #D97706 -->
<h2>진짜 차이는 <strong>이것</strong>입니다</h2>

<!-- 차트 데이터: 주 시리즈 앰버, 2번째 시리즈 그린, 대조 뉴트럴 -->
<div class="hbar-fill hbar-fill--accent">…</div>
<div class="hbar-fill hbar-fill--green">…</div>
<div class="hbar-fill hbar-fill--neutral">…</div>

<!-- 체크/크로스: ✓=그린, ×=잉크 (레드 금지) -->
<li class="check">자동으로 처리됩니다</li>
<li class="cross">수동 작업이 필요했죠</li>
```

## 금지 색상

```
❌ #00FF88 (네온그린) — 폐기. 강조는 앰버, 긍정은 #16a34a
❌ #FFD700 (골드) — 폐기. → #F59E0B
❌ #FBBF24 — 다크 배경 전용 변형. 흰 배경 영상 소스에서 금지 (썸네일은 예외)
❌ #000000 배경 / 다크 배경 — 영상 소스는 흰색 고정
❌ 레드 계열 (#dc2626 등) — 부정 표현은 뉴트럴 + × 마커로
❌ 보라/파랑/분홍 등 4색 외 모든 색
❌ Tailwind 색상 클래스 (text-yellow-400 등)
❌ #a39e98보다 옅은 회색 텍스트
❌ 작은 텍스트에 #F59E0B (→ #D97706)
```

## 미세 변형 (허용)

```css
/* 타이틀/엔딩의 은은한 앰버 비네팅 */
background: radial-gradient(ellipse at 50% 30%, rgba(245,158,11,0.10) 0%, transparent 55%), #ffffff;

/* 카드 그림자 (브랜드 토큰) */
box-shadow: 0 1px 2px rgba(20,20,19,0.04), 0 4px 14px rgba(20,20,19,0.04);
```

## 빠른 참조

| 용도 | 색상 | 코드 |
|------|------|------|
| 배경 | 흰색 | `#ffffff` |
| 텍스트/선/도형 | 잉크 | `#141413` |
| 보조 라벨 | 회갈색 | `#5e5d59` |
| **주 강조** | **앰버** | **`#F59E0B`** (작은 텍스트 `#D97706`) |
| **보조 강조** | **그린** | **`#16a34a`** |
| 빈 트랙 | 옅은 베이지 | `#efeeea` |

**규칙**: 이 표에 없는 색은 사용하지 않는다. 4색. 끝.
