# 자막 안전 영역 + SRT/CapCut 자막 가이드 (16:9)

자막은 영상 소스에 넣지 않는다 — **CapCut에서 SRT를 임포트**해 입힌다. 이 문서는 ① 슬라이드가 자막 자리를 침범하지 않도록 하는 안전 영역, ② SRT 규격, ③ CapCut 자막 권장 스타일을 정의한다.

## 화면 레이아웃 (1920x1080)

```
y=0    ─┬──────────────────────────────
        │  콘텐츠 안전 영역 (높이 850px)
        │  · 모든 슬라이드 콘텐츠는 여기에
y=850  ─┼──────────────────────────────
        │  자막 영역 (높이 230px) — 비워 둔다
        │  · [ 자막 텍스트 ]  ← 하단에서 약 162px 위치 (살짝 위로)
y=1080 ─┴──────────────────────────────
```

| 영역 | 값 | 비고 |
|------|------|------|
| 콘텐츠 안전 영역 | 상단 850px | 모든 시각 콘텐츠 |
| 자막 영역 | 하단 230px | 비워 둔다 |
| 자막 기준 위치 | **하단에서 약 162px** | CapCut 자막 Y 위치 기준 (`assemble_capcut.py` `CAPTION_Y["main"]=-0.70`이 자동 적용) |

- 보일러플레이트(`템플릿/presentation-16x9.html`)의 `--caption-safe: 21vh` 패딩이 이 영역을 자동 확보한다. **임의로 제거/축소하지 않는다.**
- 슬라이드 콘텐츠를 `position: fixed/absolute`로 하단에 붙이는 패턴 금지.

## SRT 규격

```srt
1
00:00:00,000 --> 00:00:01,400
유튜브 시작 전

2
00:00:01,500 --> 00:00:02,800
이것만 확인하세요
```

| 규칙 | 값 |
|------|------|
| 타임코드 | **원본 오디오 시간 그대로** (배속 변환 없음) |
| 한 자막 길이 | 1줄, **최대 16자 (공백 포함)** — `split_captions.py`가 기계적으로 강제 |
| 단위 | 자연스러운 문장/구 단위 (단어 단위 ❌) — AI는 글자수를 직접 맞추려 하지 말고 자연스러운 구로 묶는다 |
| 보정 | 교정사전 기계 적용(`apply_corrections.py`, 레퍼런스/교정사전.json — 16자 분할 이전) → 사전 밖만 AI가 Whisper 오류 수정·분리 단어 합침 (SKILL.md Step 3a-2) |

### 🔒 16자 하드 캡 — split_captions.py가 강제 (프롬프트 아님)

"한 컷 ≤16자"는 타이포그래픽 제약이라 **결정론적 스크립트**가 책임진다 (프롬프트로 지시해도 100+개 자막 중 일부는 반드시 어긴다 — 규칙 준수는 문서가 아니라 구조가 만든다):

- **AI의 몫**: 의미 보정 + 자연스러운 구/문장 단위 묶기. **16자를 손으로 맞추지 않는다.**
- **스크립트의 몫**: `python scripts/split_captions.py 03_자막/full.srt` — 16자 초과 컷을 어절 경계로 분할하고, 각 분할 컷의 시간은 **원래 컷 구간 안에서** 글자수 비례로 배분한다. 분할 후에도 16자를 넘으면 예외(fail loud).
- **싱크 불변**: 분할 컷은 원래 자막 구간 [start,end] 밖으로 나가지 않으므로 음성·SLIDE_TIMELINE·타임라인.json과의 싱크 계약은 그대로다 (자막 컷 수만 늘어남).
- **이중 안전망**: `assemble_capcut.py`(드래프트 조립)도 임포트 직전 같은 강제를 한 번 더 돌린다(멱등) — Step이 누락돼도 최종 CapCut 드래프트는 항상 ≤16자.
- 16자 캡·글자수 기준(`--count full`=공백 포함)을 바꾸려면 `split_captions.py`의 `MAX_CHARS`/`COUNT_DEFAULT` 한 곳만 고친다 (`assemble_capcut.py`는 이 값을 import해서 쓴다).

## CapCut 자막 권장 스타일 (흰 배경 슬라이드 기준)

| 속성 | 권장값 | 비고 |
|------|--------|------|
| 폰트 | Pretendard (또는 시스템 고딕 Black) | 브랜드 폰트 |
| 굵기 | Black/ExtraBold (900) | |
| 크기 | 1080p 기준 56px 이상 | |
| 색상 | `#141413` (잉크) | 흰 배경이라 어두운 글자 — **`assemble_capcut.py`가 임포트 시 자동 적용**(CapCut 기본색 흰색이라 흰 배경에서 안 보이는 것 방지) |
| 강조 단어 | `#D97706` (앰버 텍스트) | 키워드만 수동 강조 |
| 배경 박스/외곽선 | 없음 (필요시 아주 옅은 흰 박스) | 흰 배경 위 가독성 충분 |
| 위치 | 하단에서 약 162px, 중앙 정렬 | `assemble_capcut.py`가 `transform_y=-0.70`으로 자동 배치 (CapCut에서 추가 조정 가능) |
| 줄 수 / 길이 | 1줄, ≤16자 | `split_captions.py`가 16자로 분할하므로 항상 1줄 |
