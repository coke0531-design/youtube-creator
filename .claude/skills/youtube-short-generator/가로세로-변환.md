# Content Preservation Guide — 16:9 → 9:16 변환 & 짤림 방지

본편(16:9) 슬라이드의 인포그래픽을 쇼츠(9:16)로 가져올 때, 짤림 없이 보여주는 전략.

---

## 핵심 원칙: 재구성 > 크롭

```
✅ BEST: 세로 보일러플레이트에서 인포그래픽을 처음부터 재구성 (짤릴 일이 없다)
✅ 차선: 본편 슬라이드의 핵심 영역만 캡처/크롭해서 이미지로 배치
❌ 16:9 슬라이드 전체를 세로에 레터박싱
❌ overflow: hidden으로 넘치는 부분 잘라내기
❌ 고정 px 크기 배치 (화면 폭 초과)
```

## 1. 코드 재구성 (권장)

본편 `presentation.html`의 해당 슬라이드를 보고, 같은 데이터를 세로 패턴으로 다시 만든다:

| 본편 (16:9) | 쇼츠 (9:16) 재구성 |
|------------|-------------------|
| KPI 3열 그리드 (`kpi-grid`) | `kpi-stack` 세로 쌓기 |
| 좌우 분할 (`split-row`, `ba-container`) | `ba-stack` 상하 분할 |
| 가로 바 그룹 (넓은 라벨) | `hbar-group` (라벨 4.5em, maxWidth 30rem) |
| 도넛 520~620px | 도넛 280px급 |
| 가로 타임라인 | `vstep-list` 세로 스텝 |
| 카드 3열 | 카드 세로 1열 (핵심 2~3장만) |

패턴 코드는 [인포그래픽-패턴.md](인포그래픽-패턴.md) 참조.

## 2. 이미지 크롭 (스크린샷/외부 이미지일 때)

```bash
# ffmpeg로 원본에서 핵심 영역만 크롭 (x=400, y=200부터 1120x660)
ffmpeg -i 원본차트.png -vf "crop=1080:640:420:180" 차트-크롭.png
```

```html
<!-- 크롭 이미지를 세로 화면 폭에 맞춤 -->
<img src="cropped-chart.png" style="width: 100%; max-width: 30rem; height: auto;
     border-radius: 14px; box-shadow: var(--shadow-elevated);" class="el" style="--i:1">
```

## 3. 유효 폭 계산

```
세로 캔버스 폭:        1080px
- 좌우 패딩 (48px×2):   -96px
= 유효 콘텐츠 폭:       984px
권장 maxWidth:          900px (30rem급 — 양쪽 여유)
```

## 4. SVG 짤림 방지

```html
<!-- ✅ viewBox + 100% width → 자동 스케일 -->
<svg viewBox="0 0 600 400" width="100%" style="max-width: 26rem;">…</svg>

<!-- ❌ 고정 크기 → 1080px 화면에서 짤림 -->
<svg width="1200" height="400">
```

## 확인 체크리스트 (브라우저)

사용자에게 안내: 개발자도구 기기 에뮬레이션을 1080x1920으로 설정하고 전 슬라이드 확인.

- [ ] 차트/그래프 좌우 끝이 화면 안에 있는가?
- [ ] 텍스트가 의도하지 않은 줄바꿈 없이 들어가는가?
- [ ] 하단 440px(자막 영역)과 겹치지 않는가?
- [ ] 전체적으로 중앙 정렬이 유지되는가?
