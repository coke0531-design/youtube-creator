# 오디오 컷 & 자막 타이밍 가이드

쇼츠는 본편 나레이션의 일부 구간을 잘라 만든다. **원본 속도(1.0x) 그대로** — 배속 변환은 하지 않는다. 이 문서는 컷 패턴, SRT 타임 재계산 공식, 컷지시서 양식을 정의한다.

---

## 원칙

- 모든 원본 타임코드는 본편 `03_자막/transcript.json` 기준 (Whisper 단어 타임스탬프)
- 쇼츠 SRT는 **쇼츠 타임라인 기준**으로 재계산해서 제공 (CapCut에서 자른 오디오에 바로 맞도록)
- 실제 오디오 자르기는 **자동 조립이 표준** — `scripts/assemble_capcut.py`가 타임라인.json의 audio_cuts대로 원본 오디오를 컷 배치한다. 사용자가 CapCut에서 컷지시서대로 직접 자르는 것은 자동 조립 실패 시 폴백이다

---

## 컷 패턴 3종

### A. 연속 구간 (한 덩어리)

원본의 연속된 한 구간을 그대로 쓴다.

```
원본 오디오: [...... 01:23.5 ~ 01:51.2 ......]
쇼츠 타임라인: 00:00.0 ~ 00:27.7
공식: 쇼츠시간 = 원본시간 - 구간시작
```

### B. 불연속 2구간

중간에 한 번 건너뛴다.

```
컷 1: 원본 00:03.2~00:18.0 → 쇼츠 00:00.0~00:14.8
컷 2: 원본 00:46.5~01:02.1 → 쇼츠 00:14.8~00:30.4
```

### C. 점프컷 (3+ 구간 스티칭)

군더더기 구간을 잘라내고 후킹 구간만 이어붙인다.

```
세그먼트 정의 (원본 기준):
  A: 00:06.2 ~ 00:11.0  (훅,       4.8s)
  B: 00:16.4 ~ 00:21.7  (PROBLEM,  5.3s)
  C: 00:28.2 ~ 00:38.8  (SOLUTION, 10.6s)
  D: 00:45.1 ~ 00:52.2  (CTA,      7.1s)

쇼츠 타임라인 (누적):
  A → 00:00.0 ~ 00:04.8
  B → 00:04.8 ~ 00:10.1
  C → 00:10.1 ~ 00:20.7
  D → 00:20.7 ~ 00:27.8
```

## SRT 타임 재계산 공식

세그먼트별 독립 변환 (원본 속도이므로 빼기만 하면 된다):

```
쇼츠시간 = (원본시간 - 세그먼트 원본시작) + 세그먼트 쇼츠시작

세그먼트 쇼츠시작(누적) = 앞 세그먼트들 길이의 합
세그먼트 길이 = 원본끝 - 원본시작
```

예 (위 패턴 C): 원본 00:30.0의 단어 → C 세그먼트 → (30.0 − 28.2) + 10.1 = **쇼츠 00:11.9**

**주의**: 세그먼트 경계를 넘는 문장이 없도록 자막을 나눈다. 경계에 걸친 문장은 세그먼트 끝/시작에 맞춰 분할하거나 컷 구간을 조정한다.

## 컷지시서 양식

```markdown
# 컷지시서 — short-01 <가제>

- 원본 오디오: ../../02_음성/narration.m4a (본편 트림본 concat — transcript.json과 동일 타임베이스, 원본 속도·배속 없음)
- 세로 소스: source.html (9:16 / F 전체화면 → A 동기화 오토플레이 녹화 — SLIDE_TIMELINE 자동 전환)
- 자막: short-01.srt (쇼츠 타임라인 기준 — 오디오 컷 후 바로 임포트)
- 총 길이: 00:29.8 (콘텐츠 27.8s + CTA 2s 무음)

## 오디오 컷 (CapCut)

| 컷 | 원본 구간 | 쇼츠 타임라인 | 내용 | 카테고리 |
|----|----------|--------------|------|----------|
| A | 00:06.2–00:11.0 | 00:00.0–00:04.8 | "이거 하나로..." | 훅 |
| B | 00:16.4–00:21.7 | 00:04.8–00:10.1 | "문제는..." | PROBLEM |
| C | 00:28.2–00:38.8 | 00:10.1–00:20.7 | "방법은..." | SOLUTION |
| D | 00:45.1–00:52.2 | 00:20.7–00:27.8 | "지금 시작..." | CTA |

## 슬라이드 매핑

| 슬라이드 | 쇼츠 타임라인 | 내용 |
|---------|--------------|------|
| S1 훅 임팩트 | 00:00.0–00:04.8 | 슬램 문구 |
| S2 비교 바 | 00:04.8–00:10.1 | 기존 vs 새 방식 |
| ... | | |
| S5 CTA | 00:27.8–00:29.8 | 구독/좋아요 (무음 2초) |

## 조합 순서
1. 나레이션을 타임라인에 올리고 위 표대로 4개 구간만 남기고 컷 (컷 결과의 시작 = 쇼츠 t=0)
2. source.html을 A → SPACE 동기화 녹화한 클립을 쇼츠 t=0에 맞춰 배치 (커버가 사라지는 프레임 = 0초)
3. short-01.srt 임포트 (스타일: 세로-레이아웃.md)
4. 마지막 2초: CTA 슬라이드만, 오디오 없음
```

## 타임라인.json (기계용 동기화 데이터)

컷지시서와 같은 정보를 JSON으로도 저장한다 — `scripts/assemble_capcut.py`가 `audio_cuts`대로 CapCut 드래프트를 조립한다 (youtube-editor SKILL.md Step 7–8). 위 조합 순서는 자동 조립 실패 시 수동 폴백:

```json
{
  "type": "short",
  "timebase": "쇼츠 타임라인 t=0 기준 초",
  "audio_source": "../../02_음성/narration.m4a",
  "audio_cuts": [
    { "src_start": 6.2, "src_end": 11.0, "dst_start": 0.0 },
    { "src_start": 16.4, "src_end": 21.7, "dst_start": 4.8 },
    { "src_start": 28.2, "src_end": 38.8, "dst_start": 10.1 },
    { "src_start": 45.1, "src_end": 52.2, "dst_start": 20.7 }
  ],
  "srt": "short-01.srt",
  "source_html": "source.html",
  "duration": 29.8,
  "cta": { "start": 27.8, "duration": 2.0, "silent": true },
  "slides": [
    { "id": "S1", "index": 0, "start": 0.0, "end": 4.8, "label": "훅 임팩트" },
    { "id": "S2", "index": 1, "start": 4.8, "end": 10.1, "label": "비교 바" }
  ]
}
```

`audio_cuts`·`slides`·SRT·SLIDE_TIMELINE은 모두 같은 쇼츠 타임라인 값을 공유해야 한다 (불일치 = 싱크 깨짐).

## 결합 쇼츠 (2개 합치기)

쇼츠 2개를 하나로 합칠 때는 뒤 쇼츠의 SRT 전체에 앞 쇼츠 길이만큼 오프셋을 더한다:

```
결합자막 = 앞쇼츠자막 + 뒤쇼츠자막.map(t → t + 앞쇼츠길이)
```

---

## End-Card CTA 처리 (마지막 2초 무음 — 유지)

- 쇼츠 총 길이 = 콘텐츠 길이 + 2초
- 오디오는 콘텐츠 끝에서 종료 (CTA 구간 무음)
- SRT에 CTA 구간 자막 없음
- 컷지시서 총 길이·슬라이드 매핑에 CTA 2초를 항상 포함
