# 쇼츠 감정 설계 & 차별화

같은 본편에서 뽑은 쇼츠 2~3개가 **서로 같은 영상처럼 보이면 안 된다**. 이 문서는 쇼츠 후보를 고르고 다듬을 때 쓰는 감정 설계 기준이다. (나레이션 태깅·후보 선정 절차 자체는 [SKILL.md](SKILL.md)의 "나레이션 분석" 절이 정본이고, 여기는 그 판단 기준을 보탠다.)

---

## 1. 쇼츠끼리의 차별화 원칙

한 본편에서 나온 쇼츠들은 소재가 같을 수밖에 없다. 그래서 **전달 감정과 진입 각도**를 다르게 가져간다:

| 축 | 같아도 되는 것 | 반드시 달라야 하는 것 |
|----|----------------|----------------------|
| 소재 | 본편 주제 (동일) | — |
| 감정 | — | 쇼츠별 주력 감정 (예: 1번=놀라움, 2번=공감, 3번=지식) |
| 진입 | — | 첫 1초 훅의 각도 (결과 먼저 / 문제 먼저 / 숫자 먼저) |

- 두 쇼츠의 주력 감정이 겹치면 → 한쪽의 컷 구간이나 첫 슬라이드를 바꿔 각도를 분리한다.
- 각도 분리가 안 되면 → 합쳐서 1개로 재구성한다 (SKILL.md 의사결정 절차).

## 2. 감정 카테고리

나레이션 태깅과 쇼츠 주력 감정 선정에 쓰는 공통 어휘:

| 감정 | 시청자 반응 | 이 채널에서의 전형 |
|------|-------------|--------------------|
| 놀라움 | "이게 된다고?" | 새 기능 시연 결과, 예상 밖 수치 |
| 지식 | "알아두면 이득" | 원리 설명, 설정법, 비교 기준 |
| 공감 | "내 얘기잖아" | 시행착오, 흔한 실수 |
| 위기감 | "모르면 손해" | 함정, 비용 누수, 바뀐 정책 |
| 유머 | 웃음 | 반전, 과장 비유 (남용 금지 — 양념) |

## 3. 감정 밀도 점검 (쇼츠 확정 전)

- [ ] 쇼츠 하나에 **주력 감정이 1개**로 잡히는가? (이것저것 섞이면 흐릿해진다)
- [ ] 20~60초 안에 **감정 전환이 최소 1회** 있는가? (훅의 감정 → 본문의 감정. 단조로움 방지)
- [ ] 보고 나가는 시청자가 "뭔가 얻었다/느꼈다"고 말할 수 있는가?
- [ ] 쇼츠 2~3개의 주력 감정이 서로 다른가?

## 4. 감정 → 시각 연출 매핑

주력 감정이 정해지면 첫 슬라이드 연출을 맞춘다 ([인포그래픽-패턴.md](인포그래픽-패턴.md) 패턴 코드):

| 주력 감정 | 첫 슬라이드 연출 | 패턴 |
|-----------|------------------|------|
| 놀라움 | 결과 수치를 즉시 크게 | 빅 카운터(big-counter) + `.slam` |
| 지식 | 비교/기준을 한눈에 | 가로 바(hbar) 또는 세로 스텝(vstep) |
| 공감 | 상황 문구를 정면에 | 임팩트 타이포(.impact) |
| 위기감 | 손해/함정을 먼저 | Before-After 상하 분할(ba-stack) |
