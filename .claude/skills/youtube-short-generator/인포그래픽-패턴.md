세로 슬라이드용 인포그래픽 패턴. 모든 클래스는 `템플릿/presentation-9x16.html` 보일러플레이트에 정의되어 있다.

> 색 토큰: [design.md](../../../design.md) §2-3 — 주 강조 앰버 `#F59E0B`(작은 텍스트 `#D97706`), 보조 강조 그린 `#16a34a`, 대조는 뉴트럴.

## Pattern 1: 훅 임팩트 (첫 슬라이드)

```html
<section class="slide" data-slide>
  <p class="impact slam">월급의 <em>3배</em>를<br>버는 방법</p>
  <p class="sub el" style="--i:2; margin-top:1.2rem;">근데 아무도 안 알려줘요</p>
</section>
```

## Pattern 2: 빅 카운터 (숫자/데이터)

```html
<section class="slide" data-slide>
  <span class="section-label el" style="--i:0">절약한 시간</span>
  <p class="big-counter el" style="--i:1" data-counter data-target="127" data-suffix="시간">0시간</p>
  <p class="big-counter-label el" style="--i:2">한 달 기준</p>
</section>
```

## Pattern 3: 가로 바 비교 (A vs B)

```html
<section class="slide" data-slide>
  <span class="section-label el" style="--i:0">비용 비교</span>
  <h2 class="el" style="--i:1">외주 vs <strong>직접</strong></h2>
  <div class="hbar-group el" style="--i:2">
    <div class="hbar-row">
      <p class="hbar-label">외주</p>
      <div class="hbar-track"><div class="hbar-fill hbar-fill--neutral" style="--w:95%"><span class="hbar-value">500만</span></div></div>
    </div>
    <div class="hbar-row">
      <p class="hbar-label">직접</p>
      <div class="hbar-track"><div class="hbar-fill hbar-fill--accent" style="--w:12%"><span class="hbar-value">50만</span></div></div>
    </div>
  </div>
</section>
```

대조 대상 = `--neutral`, 핵심 = `--accent`, 둘 다 유효한 A/B = `--accent` + `--green`.

## Pattern 4: 도넛 (비율)

```html
<!-- r=120 → 둘레 ≈ 754. --off = 754 × (1 - 비율) -->
<section class="slide" data-slide>
  <span class="section-label el" style="--i:0">시간 절약</span>
  <div class="donut-wrap el" style="--i:1">
    <svg width="280" height="280" viewBox="0 0 280 280">
      <circle class="donut-track" cx="140" cy="140" r="120" stroke-width="26"/>
      <circle class="donut-arc" cx="140" cy="140" r="120" stroke-width="26" style="--circ:754; --off:204"/>
    </svg>
    <div class="donut-center">
      <p class="donut-value" data-counter data-target="73" data-suffix="%">0%</p>
    </div>
  </div>
</section>
```

## Pattern 5: KPI 세로 스택 (핵심 수치 나열)

```html
<div class="kpi-stack">
  <div class="kpi-card el" style="--i:1"><p class="kpi-label">개발 비용</p><p class="kpi-value">₩0</p></div>
  <div class="kpi-card kpi-card--accent el" style="--i:2"><p class="kpi-label">개발 시간</p><p class="kpi-value">3일</p></div>
  <div class="kpi-card el" style="--i:3"><p class="kpi-label">코드 라인</p><p class="kpi-value">2,400</p></div>
</div>
```

## Pattern 6: 세로 스텝 (프로세스)

```html
<div class="vstep-list">
  <div class="vstep vstep--done el" style="--i:1"><div class="vstep-num">✓</div><p class="vstep-text">프롬프트 작성</p></div>
  <div class="vstep vstep--active el" style="--i:2"><div class="vstep-num">2</div><p class="vstep-text">AI가 코드 생성</p></div>
  <div class="vstep el" style="--i:3"><div class="vstep-num">3</div><p class="vstep-text">결과 확인</p></div>
</div>
```

완료 = 그린(`--done`), 현재 = 앰버(`--active`), 대기 = 뉴트럴.

## Pattern 7: Before/After 상하 분할 (레드 금지)

```html
<div class="ba-stack">
  <div class="ba-card ba-card--before el" style="--i:1">
    <p class="ba-label">기존 방식</p>
    <p>매일 3시간씩 수작업</p>
  </div>
  <div class="ba-card ba-card--after el" style="--i:2">
    <p class="ba-label">바뀐 방식</p>
    <p>버튼 하나로 10분 만에</p>
  </div>
</div>
```

## Pattern 8: 엔드 CTA (마지막 2초 무음)

보일러플레이트 내장 `.slide--cta` 사용 — 👍🔔 아이콘 pop + "구독과 좋아요 부탁드립니다".

## Fallback: 임팩트 타이포 (감정/전환 구간만)

```html
<section class="slide" data-slide>
  <p class="impact">정말<em>?</em></p>
</section>
```

쇼츠에서는 감정 전환·한 마디 임팩트 구간에 한해 허용. 연속 2슬라이드 이상 텍스트만 금지.
텍스트 대신 **스티커**(`레퍼런스/스티커/` 4색 벡터 SVG — `.sticker` + `el--pop`)를 시각 주인공으로 쓰면 임팩트 타이포보다 낫다. 먼저 스캔해 재사용, 없으면 제작 후 등재 (규약: `레퍼런스/스티커/README.md`).

## 공통 규칙

- 모든 요소에 `.el` + `--i` 스태거 (순차 등장)
- 모션 연출은 **design.md §4 모션 렉시콘 용어**로 기술·구현 (하이라이트 스윕·드로우온·와이프 리빌·프로그레스 스윕 등 — 강조 preset은 한 슬라이드 1종)
- 인포그래픽 maxWidth ≤ 30rem (≈900px 느낌) — 짤림 방지
- 도넛 `--off` 계산: `둘레 × (1 - 비율)`, 둘레 = `2π × r`
- 카운터: `data-counter data-target="N" data-suffix="%"` (슬라이드 활성화 시 자동 카운팅)
