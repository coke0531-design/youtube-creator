# 세로 레이아웃 가이드 (9:16)

세로 슬라이드(1080x1920) 전용 레이아웃. **인포그래픽 퍼스트** + 자막 안전 영역 + 짤림 방지.

> 색/폰트/모션: 프로젝트 루트 [design.md](../../../design.md) §2-3 (영상 소스 모드 — 흰 배경, 4색).
> 보일러플레이트: [../../../템플릿/presentation-9x16.html](../../../템플릿/presentation-9x16.html)

## 화면 구획 (1080x1920)

```
y=0    ─┬──────────────────────────────
        │  콘텐츠 안전 영역 (1080 x 1480)
        │  · 인포그래픽 배치, 좌우 패딩 48px → 유효 폭 984px
y=1480 ─┼──────────────────────────────
        │  자막 영역 (높이 440px) — 비워 둔다
        │  · [ 자막 텍스트 ]  ← 하단에서 384px 위치
y=1920 ─┴──────────────────────────────
```

| 영역 | 값 | 비고 |
|------|------|------|
| 전체 캔버스 | 1080 x 1920 | 9:16 |
| 콘텐츠 안전 영역 | 상단 1480px | 모든 슬라이드 콘텐츠 |
| 자막 영역 | 하단 440px | 비워 둔다 (CapCut 자막 자리) |
| 자막 기준 위치 | **하단에서 384px** | CapCut 자막 Y 위치 |
| 유효 콘텐츠 폭 | 984px (좌우 48px 패딩) | 인포그래픽 maxWidth 900px 권장 |

- 보일러플레이트의 `--caption-safe: 23vh` 패딩이 자막 영역을 자동 확보한다. **임의 제거 금지.**

## 가로(본편) vs 세로(쇼츠) 차이

| 속성 | 16:9 (본편) | 9:16 (쇼츠) |
|------|------------|------------|
| 자막 영역 | 하단 230px | **하단 440px** |
| 자막 기준 위치 | 하단 약 162px | **하단 384px** |
| 유효 폭 | ~1760px | **984px** |
| 배치 방향 | 가로 여유 | **세로 스택 (flex-col)** |
| 인포그래픽 maxWidth | 1000px+ | **900px (30rem급)** |

## 16:9 → 9:16 변환 규칙

| 본편 (16:9) | 쇼츠 (9:16) | 이유 |
|-------------|-----------------|------|
| 가로 배치 (flex-row) | **세로 스택 (flex-col)** | 폭 984px < 높이 1480px |
| KPI 3열 그리드 | **kpi-stack 세로 쌓기** | 폭 부족 |
| 좌우 분할 비교 | **상하 분할 (ba-stack)** | 폭 부족 |
| 가로 타임라인 | **세로 스텝 (vstep-list)** | |
| 도넛 560~640px | **300px급** | 비례 축소 |
| 텍스트 한 단계 축소 | h2: 7vw급, 임팩트: 11vw급 | 좁은 폭 줄바꿈 방지 |
| 바 라벨 min-width 7em | **4.5em** | 라벨 폭 축소 |

## 짤림 방지

```html
<!-- ✅ maxWidth + width 100%로 안전 -->
<div class="hbar-group" style="max-width: 30rem; width: 100%;">…</div>

<!-- ✅ SVG: viewBox + 100% width (자동 스케일) -->
<svg viewBox="0 0 400 300" width="100%" style="max-width: 26rem;">…</svg>

<!-- ❌ 고정 px가 화면 폭 초과 → 짤림 -->
<svg width="1200" height="400">

<!-- ❌ overflow: hidden → 인포그래픽 일부 안 보임 -->
<div style="overflow: hidden">
```

확인 방법: 브라우저 개발자도구 기기 에뮬레이션(1080x1920) 또는 창을 세로로 좁혀 **모든 슬라이드를 훑어보라**고 사용자에게 안내.

## CapCut 쇼츠 자막 권장 스타일 (흰 배경 기준)

| 속성 | 권장값 |
|------|--------|
| 폰트 / 굵기 | Pretendard / Black(900) |
| 크기 | 1080x1920 기준 56px 이상 |
| 기본 색상 | `#141413` (잉크) |
| 강조(현재 단어/키워드) | `#F59E0B` (앰버) — CapCut 자동 캡션의 단어 하이라이트 색으로 지정 |
| 배경 박스 | 없음 |
| 위치 | 하단에서 384px, 중앙 정렬 |
| 줄 수 / 길이 | **1줄, 한 컷 ≤16자 (공백 포함)** — `scripts/split_captions.py`가 강제 |

## 타이포그래피 (보조 역할)

| 용도 | 크기 (1080x1920 기준) | 색 |
|------|----------------------|-----|
| 임팩트 숫자 (빅 카운터) | 150~220px | 앰버 |
| 훅/결론 임팩트 문구 | 110~160px | 잉크 (+앰버 em) |
| KPI 값 | 80~110px | 잉크/앰버 |
| 메인 라벨 | 56~72px | 잉크 |
| 바 라벨 | 48~56px | 잉크 |
| 섹션 라벨 | 36~44px | `#D97706` |
| 보조 설명 | 36~44px | `#5e5d59` |

**색상 규칙**: 기본 잉크 `#141413`. 보조는 `#5e5d59`. 그보다 옅은 회색 금지. 작은 텍스트 강조는 `#D97706`.

**한글 줄바꿈**: 보일러플레이트가 `word-break: keep-all`(어절 단위 줄바꿈) + 문구류 `text-wrap: balance`(줄 길이 균형)를 처리한다 — 임의 제거 금지. 세로 화면은 폭이 좁아 줄바꿈이 특히 어색해지기 쉬우니, 훅/임팩트 문구는 의미 단위로 `<br>`을 직접 넣고, 갈라지면 안 되는 짧은 구는 `<span class="nobr">`로 감싼다 (긴 구절 금지 — 짤림 위험).
