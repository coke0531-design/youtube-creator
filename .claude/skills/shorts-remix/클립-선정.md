# 클립 선정 — 롱폼에서 무엇을 어떻게 가져오는가

리믹스의 성패는 렌더가 아니라 여기서 갈린다. 근거·출처: `레퍼런스/쇼츠-리믹스-조사-2026-08.md`.

## 1. 후보 발굴 (transcript + 대본 훑기)

대본과 transcript.json을 구간별로 훑으며 아래 유형을 표시한다:

| 유형 | 신호 |
|------|------|
| 놀라운 한 줄 | 수치·결과가 한 문장에 응축된 대목 |
| 통념 뒤집기 | "다들 A라는데 사실은 B" 구조의 대목 |
| 자체 완결 통찰 | 앞뒤 없이 들어도 성립하는 원리 설명 |
| 실용 팁 | 보고 바로 따라 할 수 있는 절차 |

**데이터가 있으면 데이터 먼저**: 해당 롱폼이 이미 업로드돼 조회수가 있으면, 스튜디오 시청 지속 그래프의 되감기 피크와 댓글 타임스탬프가 최우선 후보다. 없으면 위 유형 스캔으로만 간다.

## 2. 4조건 게이트 (전부 통과해야 선정)

1. **2초 훅** — 컷 시작 2초 안에 관심을 잡는 문장이 있는가. 없으면 컷 시작점을 뒤로 옮기거나 반전 대목을 앞으로 재배치한다.
2. **단일 생각** — 한 쇼츠 = 완결된 생각 1개. 논점이 2개면 쪼개거나 버린다.
3. **깔끔한 끝** — 말이 잘린 느낌 없이 끝나는가.
4. **맥락 자립** — 본편을 안 본 사람이 이해하는가. 배경 설명이 필요하면 "최소 맥락 1문장"만 컷에 포함시킨다.

## 3. 재배치 원칙 (단순 잘라내기 금지)

- **결론·반전 선행**: 원본 순서를 지키지 말고 가장 강한 문장을 t=0으로 당긴다. cuts 배열의 순서가 곧 재배치다 (예: cuts[0]=결론 대목, cuts[1]=근거 대목).
- **군더더기 점프컷**: 배경 설명·반복·접속 멘트는 컷 경계로 제거한다. 군더더기가 40%를 넘는 후보는 훅 구간만 남긴다.
- **구조 4형 중 하나로**: 결론 먼저(역피라미드) / 오해 깨기 / 목록형(마지막이 핵심 예고) / 문제-실패-해법.
- **루프(선택)**: 마지막 문장이 첫 문장으로 자연스럽게 이어지면 반복 시청이 생긴다. 단, 결론을 숨기는 억지 루프는 역효과 — 결론은 반드시 준다.
- **감정**: 쇼츠당 주력 감정 1개 + 쇼츠 간 서로 다르게 + 내부 전환 1회 이상 (감정-설계.md 그대로).

## 4. 헤드카피 패턴 5종 (검은띠 상단, ≤2줄, 줄당 ≤15자)

| 패턴 | 예 |
|------|-----|
| 숫자형 | "조회수 3배 되는 구조" |
| 반전형 | "다들 이렇게 쓰다 망합니다" |
| 손실형 | "이 실수 하면 시간 다 버립니다" |
| 궁금증형 | "상위 1%만 아는 기능" |
| 권위형 | "구글이 공식으로 밝힌 기준" |

- 나레이션 첫 문장과 헤드카피가 같은 말을 반복하지 않게 — 헤드카피는 감추고(궁금증) 나레이션이 갚거나, 헤드카피가 결론이고 나레이션이 근거를 대는 식으로 역할을 나눈다.
- 소리 끈 시청자가 헤드카피+첫 자막만으로 주제를 알 수 있어야 한다.
- 강조어(`accent_words`)는 1~2개, 앰버로 칠해진다.

## 5. 클립계획.md 양식

```markdown
# 클립 계획 — <작업명>
## 후보 목록
| # | 구간(영상 타임코드) | 유형 | 한 줄 요약 | 4조건 (훅/단일/끝/자립) | 판정 |
## 선정 쇼츠
### short-01 — <헤드카피>
- 주력 감정: / 구조형: / cuts(재배치 순서와 이유):
- CTA: 본편과의 약속 일치 확인
```

## 6. 개수·업로드

- 10~20분 롱폼 기준 **2~4개**. 자립적인 순간 수가 상한이다 — 억지로 채우지 않는다.
- 롱폼 먼저 공개 → 쇼츠는 당일 / 다음날 / 48~72시간 / 1주 뒤 분산. 각각 관련 동영상 링크로 본편 연결.
- 쓰지 말 것: "CTA 22% 증가" 류의 출처 불명 수치를 근거로 삼지 않는다. 판단 기준은 채널 스튜디오의 "시청함(넘김 대비)"과 평균 시청 비율 실측이다.
