# youtube-creator

Claude Code용 **유튜브 영상 조립 워크스페이스**. 확정 대본과 나레이션 녹음본(+선택: 시연 영상)을 넣으면, 자막·슬라이드·캡처·CapCut 드래프트 조립까지 자동으로 만든다. **최종 컷편집·내보내기는 CapCut에서 직접** (명시 요청 시에만 완성본 합성).

주제 발굴과 대본 초안은 이 워크스페이스가 아니라 **content-oracle** 워크스페이스 담당이고, 초안 다듬기·녹음·업로드는 사용자 담당이다.

```
youtube-creator/
├── CLAUDE.md                  # Claude Code 프로젝트 지침 (전역 규칙 + 입력 계약)
├── design.md                  # 🎨 PULLING 브랜드 디자인 시스템 (SSOT — 4색·흰 배경)
├── README.md
├── 결과물/                    # 작업(영상 1편)별 산출물 — 날짜 폴더링 (규약: 결과물/README.md)
├── 레퍼런스/                  # 로고·스티커·썸네일 스타일 (스킬이 질문 없이 자동 참조)
├── 템플릿/                    # 슬라이드 보일러플레이트 (16:9 / 9:16)
└── .claude/
    └── skills/                # 프로젝트 로컬 스킬 (이 폴더 안에서만 발동)
        ├── youtube-editor/           # 16:9 본편 소스 (슬라이드 HTML + SRT + 드래프트 조립)
        └── youtube-short-generator/  # 9:16 쇼츠 소스 (+ 컷지시서)
```

## 스킬 개요

| 스킬 | 하는 일 | 트리거 예시 |
|------|---------|------------|
| **youtube-editor** | 음성+대본 → 슬라이드 HTML(SLIDE_TIMELINE 동기화 내장) + Whisper 자막 SRT + 편집지시서/타임라인.json + **헤드리스 캡처(capture.mp4) + CapCut 드래프트 자동 조립**. 마무리로 대본 끝에 '영상 요약'·'썸네일 생성 프롬프트' 섹션 append | "이 오디오로 영상 소스 만들어줘" |
| **youtube-short-generator** | 본편 → 쇼츠 2~3개: 세로 슬라이드(동기화 내장) + 쇼츠 SRT + 컷지시서/타임라인.json + 캡처·드래프트 (마지막 2초 CTA 무음) | "쇼츠로 잘라줘" |

## 표준 워크플로우

```
[외부] 대본 초안(content-oracle) → 다듬기·녹음(사용자) → [여기] 본편 소스 → 쇼츠 소스 → CapCut 검수·내보내기(사용자)
```

1. 확정 대본을 `결과물/<작업>/01_대본/`에, **나레이션 녹음본**을 `02_음성/`에 넣기 (녹음이 먼저 — 슬라이드 타이밍은 실제 발화 기준)
2. `"영상 소스 만들어줘"` → 슬라이드 HTML + full.srt + 편집지시서/타임라인.json + **capture.mp4 + CapCut 드래프트 자동 조립** + 대본 끝 '영상 요약'·'썸네일 생성 프롬프트' 섹션
3. `"쇼츠 2~3개 뽑아줘"` → 쇼츠별 세로 소스 + SRT + 컷지시서/타임라인.json + 캡처·드래프트
4. CapCut: 드래프트 열기 → 3트랙(나레이션/영상소스/자막) **검수·미세조정 → 내보내기** (자동 조립 실패 시 수동 폴백: `결과물/README.md`)
5. 제목·썸네일 카피·업로드는 사용자가 직접 ('영상 요약'·'썸네일 생성 프롬프트' 섹션이 재료)

## 요구 사항

| 항목 | 내용 |
|------|------|
| `.env` | `OPENAI_API_KEY` (Whisper 트랜스크립션) |
| pip | `pycapcut`, `playwright`(+`python -m playwright install chromium`), `imageio-ffmpeg` — 캡처·드래프트 조립용 |
| 브라우저 | 슬라이드 HTML 확인용 (F 키 = 전체화면, UI 자동 숨김 — 수동 폴백 녹화 시에도 사용) |
| CapCut | 드래프트 검수·내보내기 (국제판 비암호화 버전, 자동 업데이트 OFF) |
| Node/Remotion | **불필요** — 파이프라인은 HTML+헤드리스 캡처. `리모션/`은 전환 평가 샌드박스(보류 결론, `리모션/README.md`) |

## 디자인 시스템

모든 시각 산출물은 [`design.md`](design.md)의 PULLING 브랜드 토큰을 따른다.

- **폰트**: Pretendard / JetBrains Mono
- **4색 원칙 (영상 소스)**: 흰 배경 `#ffffff` + 잉크 `#141413` + 주 강조 앰버 `#F59E0B` + 보조 강조 그린 `#16a34a`
- **무드**: 따뜻한 미니멀, 절제된 모션 (0.45s ease-out, 순차 스태거)
- **썸네일**: 어두운 배경 + 앰버 강조 기본 (CTR 우선 예외 허용)
