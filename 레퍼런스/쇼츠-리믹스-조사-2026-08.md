# 쇼츠 리믹스 조사 종합 (2026-08-13)

shorts-remix 스킬의 근거 자료. 오케스트레이션 조사 4갈래(규격·스타일·추출 전략·로컬 감사)를 종합했다.
표기: **[공식]** = YouTube/CapCut 공식 문서, **[업계]** = 반복 관찰되는 관행(측정 근거 없음), **추정(근거)** = 계산 역산.

## 2. 검은띠 + 헤드카피 레이아웃 (1080x1920 기준)

공개 표준이 없는 영역이라 세이프존에서 역산한 배분(A안, 원본 안 자름):

```
y    0 ~  200   상단 UI 회피 (비움)
y  200 ~  500   헤드카피 블록 (300px, 2줄 이내)
y  500 ~ 1108   16:9 본편 (1080x607.5)
y 1108 ~ 1460   자막 구역
y 1460 ~ 1920   하단 UI 회피 (비움, 460px — 유튜브 하단 UI 330~400px + 여유)
```

- 띠 색: 순검정보다 `#0A0A0A` (OLED에서 영상 경계 덜 튐, 관행)
- 헤드카피: 두꺼운 폰트(검은고딕·Pretendard Black), 70~90px(추정: 1080폭 ÷ 줄당 12~14자), 흰색 + 강조어 1색, 2줄 상한, 줄당 15자 이내
- 자막: 48~60px, 흰색+검정 외곽선 3px, 하단에서 400px 이상 위, 한 컷 ≤16자(쇼츠는 8~12자 1줄이 실질 상한)
- CapCut 폰트 단위 환산 [공식]: 텍스트 높이(px) = 입력값 × 0.24 (모바일 슬라이더 상한 ≈72px — 헤드카피는 PC 직접 입력 필요)

## 3. 헤드카피 패턴 5종 (알파컷 정리)

1. **숫자형** — "조회수 3배 되는 구조"
2. **반전형** — "다들 A라는데 사실은 B"
3. **손실형** — "이 실수 하면 쇼츠 망한다" (손실 민감도가 이득의 2배)
4. **궁금증형** — "성공한 쇼츠의 공통점" (핵심을 감춘다)
5. **권위형** — "조회수 1억 쇼츠들의 공통점"

보조: 훅 멘트 15자 이내. 조회수는 편집 퀄이 아니라 첫 3초가 가른다.

## 4. 클립 선정·재가공 (제일 중요)

**클립 4조건** [업계 합의]: ① 첫 2초 안에 훅 ② 한 개의 완결된 생각 ③ 깔끔한 끝맺음 ④ 맥락 자립(본편 안 봐도 이해).

**잘 뽑히는 대목**: 놀라운 한 줄 / 통념 뒤집기·반전 / 자체 완결 통찰 / 바로 따라 하는 실용 팁.

**재가공 원칙**: 단순 잘라내기가 아니라 **재배치** — 결론·반전을 앞으로 당기고, 군더더기(배경 설명·반복)는 점프컷. OpusClip 바이럴 점수 4축 = 훅·흐름·가치·트렌드 [공식 문서]. AI 자동 선정은 초벌용(약 40% 폐기율 보고) — 최종 선정은 사람/상위 판단.

**데이터 역산법**: 롱폼에 조회수가 쌓였다면 스튜디오 시청 지속 그래프의 되감기 피크 + 댓글 타임스탬프가 최우선 후보.

**구조 4형** (정보성): 결론 먼저(역피라미드) / 오해 깨기 / 목록형(N가지, 마지막이 핵심 예고) / 문제-실패-해법. 루프 기법: 마지막 문장이 첫 문장으로 이어지게 (억지 루프는 역효과).

**대본 구조**: 훅 → 최소 맥락(1문장) → 전개 → 보상 → 다음 단계. 얼굴 없는 슬라이드 채널은 3~5초마다 화면 변화(텍스트 등장·줌·전환도 변화로 침).

## 5. 본편 유입 설계 [공식]

- **관련 동영상 링크**: 스튜디오 → 쇼츠 → 관련 동영상 선택 (고급 기능 권한 필요). 채널 핸들 아래 링크로 노출.
- 마지막 5초 CTA를 말+화면 양쪽으로. 쇼츠의 약속과 링크 대상 일치.
- **롱폼 첫 5~10초가 쇼츠에서 약속한 주제를 바로 갚아야 한다** (유튜브 공식 블로그 강조).
- 개수·간격: 롱폼 1편당 2~4개(10~20분 기준), 롱폼 먼저 → 쇼츠는 당일·다음날·48~72h·1주 뒤로 분산.
