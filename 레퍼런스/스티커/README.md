# 스티커 애셋 라이브러리 (SSOT)

플랫 인포그래픽의 시각적 단조로움을 보완하는 **재사용 일러스트 애셋**. 감정 전환/리액션/강조 장면의 시각 주인공으로 쓴다. 브랜드 규칙은 design.md §5 「스티커 애셋 규칙」이 정의하고, 파일명 규약·대장은 이 파일이 SSOT다.

## 제작 규칙 (벡터 4색 통일)

- **SVG 벡터만** (필요 시 Lottie JSON). 실사·자유색 래스터 금지 — 실사 질감이 필요하면 스티커가 아니라 이미지 카드로.
- 색은 design.md 4색 원칙의 색값만: 잉크 `#141413` / 앰버 `#F59E0B` / 그린 `#16a34a` + 뉴트럴(`#f7f6f4`, `#efeeea`, 흰색). 작은 텍스트가 들어가면 `#D97706`.
- viewBox `0 0 240 240` 기준, 배경 투명, **선 두께 ≥6** (영상 축소 가시성 — design.md §6과 같은 이유).
- 제작 주체: AI가 SVG 코드로 저작한다 (Claude 직접 또는 Codex 위임 — 완성본은 4색·두께 게이트 통과 확인 후 등재).

## 파일명 규약 (파일명이 곧 검색이다)

```
<주제>-<표정·동작>-<주색>.svg     예: 전구-반짝-앰버.svg, 체크-완료-그린.svg
```

새 스티커를 만들면 반드시 이 규약으로 저장하고 아래 대장에 1행 추가한다 — 다음 영상에서 재제작하지 않고 재사용.

## 사용법 (슬라이드)

1. 필요한 감정/상황을 파일명으로 **먼저 스캔**해 재사용, 없을 때만 신규 제작 후 등재.
2. 사용할 파일을 결과물 `04_영상소스/`로 복사(상대경로 참조 — 캡처는 결과물 폴더 기준).
3. 템플릿의 `.sticker` 컴포넌트로 배치. 등장 = `el--pop`(팝), 시선 유도 = `pulse`:

```html
<div class="sticker el el--pop" style="--i:1; --sw:380px">
  <img src="전구-반짝-앰버.svg" alt="">
</div>
```

- 크기: 16:9 기본 340px(주인공이면 460px+ — 슬라이드-디자인 문서 크기 규칙), 9:16 기본 240px.
- 한 슬라이드에 스티커 1개가 원칙 (포컬 포인트 1개 원칙과 동일).
