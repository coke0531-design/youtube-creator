# 레퍼런스

스킬이 **묻지 않고 자동으로 참고**하는 공용 에셋 폴더.

| 폴더 | 용도 | 사용 스킬 |
|------|------|----------|
| `썸네일/` | 썸네일 스타일 레퍼런스 이미지 (jpg/png). 여기 있는 이미지를 자동으로 `image_input`에 전달해 스타일을 따라 만든다. **마음에 드는 썸네일(내 채널 과거작, 벤치마킹 채널)을 넣어두면 됨** | 썸네일 프롬프트 (editor Step 9-2) |
| `인물/` | 썸네일 합성용 인물 사진 (정면/감정 표정 위주) | 썸네일 프롬프트 (editor Step 9-2) |
| `로고/` | 슬라이드에 자주 쓰는 제품 로고 (svg/png, 256px+) — 영상 소스 제작 시 작업 폴더로 복사해 사용 | youtube-editor, youtube-short-generator |
| `스티커/` | 재사용 일러스트 스티커 (4색 벡터 SVG) — 감정 전환/리액션 장면의 시각 주인공. 파일명 규약·대장·제작 규칙 = `스티커/README.md`(SSOT). 먼저 스캔해 재사용, 없으면 제작 후 등재 | youtube-editor, youtube-short-generator |
| `교정사전.json` | Whisper 오인식 영구 교정 사전 — `scripts/apply_corrections.py`가 full.srt에 기계 적용. **문맥 무관 고유명사·맞춤법·표기만 등재**(동음이의·문맥 의존 금지 — 파일 내 `_규칙` 참조) | youtube-editor |

## 규칙

- 썸네일 레퍼런스는 **최신 수정순으로 최대 5장**을 자동 사용한다. 특정 이미지를 지정하고 싶으면 파일명을 대화에서 언급하면 된다.
- 폴더가 비어 있으면 묻지 않고 프롬프트만으로 생성한다.
- 파일명은 내용을 알 수 있게: `밝은버전_아이보리.jpg`, `인물_놀람.png` 등.
