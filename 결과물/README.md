# 결과물

영상 1편 = 작업 폴더 1개. 모든 산출물(대본/자막/영상 소스/쇼츠)이 작업별로 모인다. (대본 초안은 content-oracle에서, 제목·썸네일 카피는 사용자가 직접 — 이 워크스페이스는 조립까지.)

## 폴더 규약

```
결과물/
└── YYYY-MM-DD_<주제-슬러그>/      예: 2026-06-10_클로드-활용-노하우/
    ├── 작업정보.md                ← 작업 메타 (필수, 산출물 생길 때마다 갱신)
    ├── 편집지시서.md              ← 본편: 슬라이드 ↔ 오디오 타임코드 (사람용 CapCut 가이드)
    ├── 타임라인.json              ← 같은 데이터의 기계용 (pyCapCut 드래프트 자동 조립 입력)
    ├── 00_리서치/                 ← 소재 확정(5필드) 시 생성: 자료조사.md(출처표) + VOC.md(선택)
    ├── 01_대본/script.md          ← 나레이션 정본 — `## 썸네일`/`## 본문` 파트 문법 지원(본문만 녹음/STT 대상)
    ├── 02_음성/                   ← 녹음 파일을 여기에 넣어주세요 (mp3/wav/m4a) — 녹음이 먼저!
    ├── 03_자막/full.srt           ← + transcript.json (Whisper 원본)
    ├── 04_영상소스/presentation.html  ← SLIDE_TIMELINE 내장 + capture.mp4 (헤드리스 캡처) + ov<n>.mp4(오버레이)
    ├── 영상 소스/                 ← (오버레이 모드) 사용자 제공 시연/실사 영상 원본
    ├── 캡컷 조립 재료/            ← 조립·검수 필요 파일만 모음(하드링크) — 이 폴더 하나만 보면 됨
    ├── 05_쇼츠/short-01/          ← source.html + short-01.srt + 컷지시서.md + 타임라인.json
    └── 완성본/                    ← (명시 요청 시만) render_final.py 합성 결과 final.mp4
```

## 작업정보.md 양식

```markdown
# <영상 제목(가제)>

- 날짜: YYYY-MM-DD (시작) / YYYY-MM-DD (최종 수정)
- 유형: 풀링(리드젠)
- 길이: 미드폼 6~8분 (예정)
- 상태: 기획 | 리서치 | 대본 | 소스 제작 | 컷편집 대기 | 업로드 완료

## 사전자료 (5필드)
- 영상 주제:
- 썸네일 멘트:
- 영상 제목:
- 타깃:
- 클릭 이유:
- (선택) 고정 도입부:

## 산출물
- [ ] 자료조사 (00_리서치/자료조사.md) ← 외부 사실 필요 시 · VOC.md(선택)
- [ ] 대본 (01_대본/script.md — 순수 나레이션) + 기획메모.md
- [ ] 음성 (02_음성/) ← 사용자 녹음
- [ ] 자막 (03_자막/full.srt)
- [ ] 영상 소스 (04_영상소스/presentation.html — SLIDE_TIMELINE 포함)
- [ ] 편집지시서 (편집지시서.md) + 타임라인.json
- [ ] (오버레이 모드) ov<n>.mp4 (04_영상소스/ — encode_overlays.py 배속 인코딩)
- [ ] 캡처 (04_영상소스/capture.mp4 — 헤드리스 frames 캡처)
- [ ] CapCut 드래프트 (3트랙, 오버레이 있으면 4트랙 자동 조립 — 절대경로 참조라 폴더 이동 시 --replace 재조립)
- [ ] 캡컷 조립 재료/ (stage_capcut_kit.py)
- [ ] 대본 끝 '영상 요약'(고정 해시태그+챕터) + '썸네일 생성 프롬프트' 섹션
- [ ] 쇼츠 N개 (05_쇼츠/)
- [ ] (명시 요청 시) 완성본 (완성본/final.mp4 — render_final.py)

## 메모
- (작업 중 결정 사항, 특이사항 기록)
```

## CapCut 작업 (표준 = 자동 조립)

**표준 경로**: AI가 헤드리스 캡처(`scripts/capture_slides.py`) → 드래프트 자동 조립(`scripts/assemble_capcut.py`) → 조립 재료 모음(`scripts/stage_capcut_kit.py`)까지 끝내 놓는다.
CapCut을 열면 3트랙(나레이션/영상소스/자막, 오버레이 있으면 슬라이드 위 '영상소스' 트랙이 추가된 4트랙)이 조립돼 있다 — **검수·미세조정 → 내보내기**만 하면 된다. 수동 폴백 시에는 `캡컷 조립 재료/` 폴더 하나만 보면 된다.

### 수동 조합 (자동 조립 실패 시 폴백)

1. `02_음성/` 나레이션을 타임라인에 올린다 (원본 속도 그대로)
2. `04_영상소스/presentation.html` 열기 → `F` 전체화면 → **화면 녹화 시작 → `A` → `SPACE`** (누르는 순간 = 오디오 0초). SLIDE_TIMELINE이 끝까지 자동 재생되어 싱크가 보장된다
3. 녹화 클립에서 **커버가 사라지는 프레임**을 오디오 시작점에 맞춰 배치
4. `03_자막/full.srt`를 자막으로 임포트 (권장 스타일은 스킬 문서의 자막 가이드 참조)
5. 쇼츠는 `05_쇼츠/short-NN/컷지시서.md`(또는 타임라인.json의 audio_cuts)대로 오디오를 잘라 배치 → 동기화 녹화 클립을 쇼츠 0초에 정렬

## 규약 외 파일

- 작업 중 만든 **일회용 보조 스크립트**(예: 로컬 전사 `transcribe_local.py`)는 산출물이 아니다 — 해당 단계 폴더에 두되 작업정보.md 메모에 용도를 1줄 기록한다.
- **캡처 임시 폴더**(`04_영상소스/_capture_segs/`)와 루트 `capture.log`는 캡처 성공 시 정리된다. 잔존해 있으면 = 캡처가 실패/중단된 것 — 작업정보.md 상태를 확인하고 재캡처 전에 삭제한다.
